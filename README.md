# Zee Collection AI Copilot
### Open-Source E-Commerce AI Search for South Asia

Live Demo: https://zeecollection.tech
License: MIT

**Problem:** 10M+ small e-commerce stores in Pakistan/India can't afford AI search. Users search "shaadi watch under 5000" and get 0 results.

**Solution:** Lightweight, open-source AI copilot that understands Urdu/Hinglish + English natural language for product discovery.

#### Features
- 🔍 Natural language search: "wedding watch for men under 5000 PKR"
- 🌐 Urdu / Roman Urdu + English support
- ⚡ Runs on low-cost hosting (Cloudflare + open LLMs)
- 🛒 Plug & play for any Shopify/WooCommerce store

#### Tech Stack
- Python, OpenAI embeddings, Vector DB
- MIT Licensed, 100% open-source
